How it works

세 단계로, 도시 블록의 절감 효과까지

실제 도시 데이터를 불러와 BADTM AI 자율제어를 적용하고, 4대 지표와 보고서까지 한 번에 산출합니다.

01

주소·도시 데이터 수집

OpenStreetMap으로 실제 건물군을 인식하고, 건축물대장·지역 기후값을 자동으로 불러옵니다.

02

BADTM AI 자율제어 적용

03

4대 지표·보고서 산출

🗺️ 카카오맵을 표시하려면 JavaScript 키가 필요합니다

카카오맵은 도메인에 등록된 앱 키가 있어야 표시됩니다. 아래 순서로 무료 키를 발급받아 넣어주세요.

  1. 카카오 개발자 사이트(developers.kakao.com)에서 애플리케이션 생성
  2. [앱 설정 → 앱 키]의 JavaScript 키 복사
  3. [플랫폼 → Web]에 사이트 도메인 등록 (예: GitHub Pages 주소)
  4. index.html 상단 스크립트의 KAKAO_JS_KEY 값에 붙여넣기

키를 넣기 전에도 나머지 분석 기능(디지털 트윈·4대 지표·보고서)은 정상 작동하며, 위 로드뷰 버튼은 키 없이도 카카오 로드뷰를 새 탭으로 바로 엽니다.

Glossary

용어 쉽게 이해하기

논문에 나오는 핵심 용어를 한 줄로 풀어 설명합니다. 항목을 누르면 자세한 내용이 열립니다.

생체모방자연에서 배우는 설계+
자연 생물의 구조·기능·원리를 공학과 건축 설계로 옮겨오는 접근입니다.예: 솔방울이 습도에 따라 스스로 열리고 닫히는 원리를 건물 차양에 적용합니다.
키네틱 파사드움직이는 건물 외피+
고정된 벽이 아니라 햇빛·온도에 맞춰 움직이며 빛과 열을 조절하는 건물 외피입니다.예: 여름 낮에는 닫아 더위를 막고, 겨울 아침에는 열어 햇볕을 들입니다.
BADTM자연 원리 → 숫자로 번역+
생체-건축 데이터 변환 매트릭스(Bio-Architectural Data Translation Matrix). 자연의 원리를 컴퓨터가 다룰 수 있는 숫자(상태·행동·보상)로 번역하는 방법론입니다. 이 연구의 대표 방법입니다.예: "습하면 닫는다"를 "습도 값 → 루버 각도"라는 제어 변수로 바꿉니다.
USS건물들이 협력하는 이론+
도시 공생 외피(Urban Symbiotic Skin). 건물 한 채가 아니라 여러 건물이 외피로 협력해 도시 규모에서 에너지를 아끼는 이론입니다.예: 한 건물의 남는 전기를 옆 건물이 쓰고, 전력 첨두 시간을 서로 비껴갑니다.
AA-FrameworkAI를 갈아 끼우는 구조+
알고리즘 독립 프레임워크(Algorithm-Agnostic Framework). 설계 논리는 그대로 두고, 안에 들어가는 AI만 자유롭게 바꿔 끼울 수 있는 구조입니다.예: SAC를 쓰다가 더 좋은 AI가 나오면 설계 변경 없이 그대로 교체합니다.
강화학습시행착오로 배우는 AI+
AI가 시행착오를 반복하며 '보상'을 최대화하는 방법을 스스로 배우는 학습 방식입니다.예: 파사드를 이리저리 움직여 보며 가장 쾌적하면서 에너지가 적게 드는 방법을 찾아냅니다.
SAC · PPO대표 강화학습 알고리즘+
강화학습의 두 대표 알고리즘입니다. SAC는 탐색이 풍부하고 데이터 효율이 높으며, PPO는 학습이 안정적입니다.본 연구에서 둘의 성능 차이는 2.6%p로 사실상 동등했습니다(알고리즘 독립성).
EUI에너지 사용 강도+
건물이 1㎡당 1년에 쓰는 에너지량(kWh/m²·yr)입니다. 낮을수록 효율적입니다.본 연구: 187.4 → 108.7 로 42% 감소했습니다.
PMV열쾌적 지표+
예측 평균 온열감. 재실자가 느끼는 더위·추위를 −3~+3으로 나타낸 쾌적 지표로, 0에 가까울수록 쾌적합니다.여기서는 쾌적 범위를 충족한 시간 비율(충족률)로 사용합니다.
UDI적정 자연광 지표+
유효 주광 조도. 너무 어둡지도 눈부시지도 않은 '적정한 자연광'이 확보된 시간의 비율입니다. 높을수록 조명 에너지가 절약됩니다.직사광을 억제하면서도 충분한 밝기를 확보하는 균형이 핵심입니다.
Meso-2핵심 건물군 단위+
USS 4층위(Micro·Meso-1·Meso-2·Macro) 중 3~10개 동 규모의 건물군입니다. 협력 효과가 처음으로 뚜렷해지는 핵심 단위입니다.이 규모에서 부하 분산과 피크 완화가 창발적으로 나타납니다.
EnergyPlus · OSF시뮬레이션·공개 저장소+
EnergyPlus는 미국 에너지부의 표준 건물 에너지 시뮬레이션 엔진입니다. OSF는 연구 절차·데이터를 미리 공개해 재현성을 보장하는 공개 저장소입니다.본 연구의 분석 프로토콜은 osf.io/s385d 에 등록·공개되어 있습니다.
