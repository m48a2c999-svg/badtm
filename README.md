# Kinetic Skin Lab — 역삼 블록 키네틱 파사드 연구 사이트

박사학위논문 「건물군 키네틱 파사드의 데이터 기반 성능 평가 프레임워크 연구 — 역삼역 일대 업무시설의 시뮬레이션·실측 비교와 생체모방 제어 원리의 검증 —」(조승완, 국민대학교 일반대학원 건축학과, 지도교수 박미애)의 요약·결과·자료·도구를 웹에서 보는 정적 사이트입니다.

- 사이트: https://m48a2c999-svg.github.io/badtm/
- 기준 원고: 2026-10-24 검토용 v11(계산 기준: 대장 면적 보정, 계산 간격 10분; 가설 판정 용어 채택·기각·미검토)
- 논문 전문(PDF)은 저자 확인 뒤 공개합니다. 사이트의 요약문은 논문 본문을 옮긴 것이 아니라 사이트용으로 다시 쓴 글입니다.

## 수치에 관한 주의

- 성능 수치는 모두 EnergyPlus 23.2(서울 TMYx 2011–2025) 시뮬레이션 값입니다. "실측"은 건축HUB 월별 사용량과의 비교만 가리킵니다.
- 최대 전력은 1시간 평균 전력의 연간 최댓값이며, 같은 모델 안의 안 사이 상대 비교로만 해석합니다.
- 시뮬레이션 탭의 실내 조도·작동 계산은 브라우저에서 도는 단순 근사(CIE 흐린 하늘, 슬랫 기하 투과 + 반사 근사, 평균 내부 반사)이며 논문의 EnergyPlus 결과가 아닙니다.
