# Facade Retrofit Lab — 서울 업무시설 밀집지역 외피 개량 검증

박사학위논문(예비심사 원고, 2026-10-26 검토용) 「서울 업무시설 밀집지역의 외피 개량에 따른 에너지 성능 검증 — 키네틱 파사드 적용 시뮬레이션을 중심으로 —」(조승완, 국민대학교 일반대학원 건축학과, 지도교수 박미애)의 결과·건물·대안을 연구 데이터베이스로 보는 정적 사이트입니다.

- 사이트: https://m48a2c999-svg.github.io/badtm/
- 모든 성능 수치는 EnergyPlus 23.2 시뮬레이션 값입니다. "실측"은 건축HUB 월별 전기 사용량과의 비교만 가리킵니다.
- 논문 전문(PDF)은 저자 확인 뒤 공개합니다.

## 구성

| 경로 | 내용 |
|---|---|
| `#/` | 개요 — 제목·목적·연구 질문·독창성·범위·예비 결과 요약 |
| `#/site` | 대상지·건물 — 4개 대블록 257동 지도와 목록, 건물별 개량 전후 결과·월별 실측 비교 |
| `#/alts` | 개량 대안 — 고정형 차양 3종, 키네틱 파사드 6종(범위 밖 전기변색 유리는 참고) |
| `#/results` | 결과 — 상세 3개 동, 257동 분포, 블록 합산 최대 전력(보조 지표) |
| `#/traits` | 건물 특성별 — 가린 정도·평면 면적·층수별 효과, 순위 상관, 예비 적용 조건 |
| `#/valid` | 실측 비교 — ASHRAE Guideline 14 대조 |
| `#/bio` | 생체모방 제어 원리 4개(부록) — 원리, 규칙, 판정, 본 연구에서의 위치 |
| `#/plan` | 향후 계획 — 재계산, 서울 3대 업무권역(CBD·YBD·GBD) 블록별 전체 건물 |
| `#/db` | 데이터베이스 — 구성, SQL 질의, SQLite·CSV 내려받기 |

## 데이터베이스

- `data/db/research.sqlite` — 사이트의 모든 표와 그림의 출처. 브라우저에서 sql.js(1.10.3)로 엽니다.
- `data/db/csv/*.csv` — 표별 CSV(UTF-8 BOM).
- `tools/build_db.py` — 계산 결과 내보내기(`archive/v11/data`)와 원자료에서 데이터베이스를 다시 만드는 스크립트.

## 이전 판

- `archive/v11/` — 2026-10-24 검토용 v11 원고 기준 사이트(보관). 3D 대상지·태양 경로, 검증 원장, 문헌 DB 등을 그대로 볼 수 있습니다.
