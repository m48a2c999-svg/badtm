# r4: 네 지역(도심·강남·여의도·마포) 같은 규칙 자료와 계산 (2026-11-23)
- fetch_osm.py: 가구(3권역은 기존 UPIS 가구, 마포는 마포대로 30 m 안 상업지역 − 도시계획도로)와 OSM 건물(가구 밖 400 m까지)
- collect.py: 건축물대장 표제부 결합(가구 안 전부 + 1차 대상 350 m 안 가구 밖 전부). 지번 결합 실패 보완(윤곽 안 다른 점, 같은 본번 부번 조회)
- select_r4.py: 같은 지번 윤곽–표제부 짝짓기(주건축물 2건 이상이면 건축면적·층수로 짝짓기), 대상 선별(업무시설 주·기타용도, 지상 6층 이상), 높이 순서 통일, 가려진 정도, EnergyPlus 입력
- energy_r4.py: 대상 지번 월별 전기·가스(2023~2024)
- seed/: 2026-11-01 3권역 자료(카카오 지번·표제부·에너지) — 캐시 씨앗
- 인증키는 GitHub 비밀값(KAKAO_REST_KEY, DATA_GO_KR_KEY)으로만 쓰고 파일·로그에 남기지 않는다. 모든 계산값은 시뮬레이션 값이다.
